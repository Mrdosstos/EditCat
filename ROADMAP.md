# Roteiro do EditCat

Legenda: **[local]** roda no navegador sem servidor · **[modelo]** precisa de um modelo de IA no navegador · **[servidor]** precisa de uma API externa.

## Feito
- Camadas, modos de mistura, chroma key, máscaras, quadros-chave, congelar, inverter, espelhar, girar, desfoque e mosaico.
- Separar áudio, remover silêncios, cortar no ritmo, equalizar volume, abaixar música na fala, narração, efeitos de voz, limpar voz.
- Legendas automáticas (Whisper no navegador), roteiro para legendas, estilo único e destaque da palavra falada.
